# Sara Monteiro — Citation List

Static GitHub Pages citation site.

## Files

- `index.html` — page content
- `styles.css` — site styling
- `script.js` — search, filters, copy buttons, and theme toggle
- `CITATIONS.md` — plain Markdown citation list
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

## Publish on GitHub Pages

Upload all files to the repository root, then set GitHub Pages to deploy from the `main` branch / root directory.
